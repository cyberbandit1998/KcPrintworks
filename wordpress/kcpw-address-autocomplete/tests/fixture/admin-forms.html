Add a form

  • WooCommerce Checkout Block (the new checkout)
    Shipping and billing address of the block-based checkout. Recommended for stores whose checkout page shows "Contact information" and "Shipping address" steps.
  • WooCommerce classic checkout and My Account addresses
    The shortcode-based checkout and the Edit address screens of My Account.
  • Contact Form 7
    Expects fields named address, city, state, zip and country. Rename yours to match, or correct the selectors with the Visual Selector Tool.
  • WPForms (Address field)
    The Address field of WPForms: street, apartment, city, state, postal code, country.
  • Gravity Forms (Address field)
    The Address field of Gravity Forms (inputs end in _1 street, _2 line 2, _3 city, _4 state, _5 ZIP, _6 country).
  • Elementor Pro form
    Expects field IDs address, city, state, zip and country (set in each field's Advanced tab).
  • Fluent Forms (Address field)
    The Address field of Fluent Forms.
  • Ninja Forms
    Expects fields whose keys are address, city, state, zip and country.
  • Formidable Forms (Address field)
    The Address field of Formidable Forms.
  • Another form (pick the fields with the Visual Selector Tool)
    Any HTML form: click each field on your own page and the tool writes the selector for you. Set up
