Nothing on this page is on unless you switch it on. By default this plugin sends no address, no name and no visitor detail to anyone but Google (for the suggestions the visitor asked for). The usage counters on the Dashboard are whole numbers only.

Webhook


Send a message


Currently on.

Needs the address check (above) to be on, because that is what finds problems. By default a message says only that a check found a problem, which kind, your site and the form: no address. It is sent once, without waiting for an answer, and the same address does not ring twice within an hour. It is switched on only with the first box, the consent box and a valid https address.

Checkout counting

Currently on.

Two numbers on the Dashboard, added up per day, so you can see roughly how many people start checkout and do not finish. Nothing about any person or order is stored (a short-lived marker keyed by the order number stops a refreshed thank-you page counting twice). Counted only while the plugin is Live. It is a rough guide: visitors who block scripts, or pay with a wallet button, are not all counted.

Location hint
Where the country comes from


Currently on.

It only softens the order of suggestions (they never get limited or filled by it), and a form that already limits the countries ignores it. A position from a lookup service is rounded to about a city before it is used, and nothing is stored with the visitor's address except a one-way hash, for six hours, so a returning visitor is not looked up again. Using a lookup service shares visitors' IP addresses with a third party: check that your privacy notice says so.
