# Home page banner

`hero-banner.jpg` is a **neutral dark placeholder** so the page has no broken image. Replace it with the owner's
photograph (same file name, no code change).

- Use the photo **without** the headline and buttons baked in. The headline, copy, and buttons on the home page are
  real text laid over the image (accessible, searchable, and they stay sharp on every screen).
- About 2400 x 1100 px, JPEG, under about 300 KB. The printers sit on the right of the frame; the left is covered by a
  dark scrim behind the text, so keep the busiest detail on the right.
- It is decorative (`alt=""`), so nothing in it needs a description.
