# Proposed Category Structure (for review)

**Nothing here has been applied.** It is a proposal for you to correct. Generated from the product export by
[`scripts/discovery/propose-categories.mjs`](../../scripts/discovery/propose-categories.mjs); the same mapping as a spreadsheet,
with an empty `owner_decision` column, is [`category-plan.csv`](category-plan.csv). Every row shows the rule that placed it, so a
wrong placement is fixed by editing one rule.

## Why change anything

- **50 of 66 published products are "Uncategorized"** and only 3 are in a real category. The "Desk Toys" category holds a
  card game (#187). Navigation, category pages, and search results all suffer.
- The cause is partly **code**: "KCPW Auto New Arrivals Rotator" moves products in and out of New Arrivals and "back to their regular categories",
  and "New Arrivals Merchandising" assigns the latest imports to Game Night / New Arrivals ([PLUGINS.md](PLUGINS.md) P6). Those plugins would
  **overwrite a manual cleanup**, so retiring or reconfiguring them is part of the plan.

## Proposed structure: five stored categories plus computed collections

| Category | URL slug | Products |
|---|---|---|
| Card Game Cases | `card-games` | 44 (36 after retiring duplicates) |
| Board Game Cases | `board-game-cases` | 5 (4 after retiring duplicates) |
| Playing Card & Deck Boxes | `card-and-deck-boxes` | 7 (7 after retiring duplicates) |
| Battery & Utility Storage | `battery-and-utility-storage` | 7 (4 after retiring duplicates) |
| Gifts, Tags & Desk Toys | `gifts-tags-and-desk-toys` | 3 (3 after retiring duplicates) |

**Computed collections** (generated by the storefront from product data, not stored as categories, so nothing needs to rotate or be reassigned):

| Collection | Rule | Replaces |
|---|---|---|
| New Arrivals | newest N published products by date | "Auto New Arrivals Rotator" and "New Arrivals Merchandising" |
| Personalized | product has personalization options | the word "Personalized" in titles |
| On Sale | has a sale price | the sale banner logic |
| Game Night | a curated list you choose (a tag) | the "Game Night" category |
| Bundles | products tagged as bundles (#587, #877) | nothing today |

## Browsing 44 card-game cases

Card Game Cases would hold about two thirds of the catalog, which is only browsable with a **filter by game** (Skip-Bo, Phase 10, UNO, Flip 7, Monopoly Deal,
Five Crowns, and so on). Proposal: add a "Game" attribute or tag per product from a list you confirm, and offer it as a filter. This is better than 20 sub-categories
for a catalog of this size.

## Keeping URLs and SEO

Existing category URLs have SEO titles set by "KCPW Category SEO Titles" and are in feeds and the sitemap. To avoid breaking them:

| Existing category (slug) | New treatment | Redirect needed |
|---|---|---|
| Card Games (`card-games`) | Becomes **Card Game Cases**; **keep the slug** | none |
| Game Night (`game-night`) | Becomes a curated **collection** at the same URL | none |
| New Arrivals (`new-arrivals`) | Becomes a computed **collection** at the same URL | none |
| HomeGoods (`homegoods`) | Folded into Battery & Utility Storage | 301 to `battery-and-utility-storage` |
| Boxes & Bins (`boxes-bins`) | Folded into Battery & Utility Storage | 301 to `battery-and-utility-storage` |
| Desk Toys (`desk-toys`) | Folded into Gifts, Tags & Desk Toys | 301 to `gifts-tags-and-desk-toys` |
| Uncategorized (`uncategorized`) | Retired. "Google Index Cleanup" already redirects this archive | 301 to `/shop/` |

New categories need new SEO titles and descriptions; the existing titles should be reviewed (the custom SEO plugin source is needed, Q10).
