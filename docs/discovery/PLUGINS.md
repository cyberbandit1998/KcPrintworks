## 3. What this changes in my earlier recommendations

- **Personalization (ADR-007):** now leaning first-party (`kcpw-core` option module); no add-on plugin to adapt.
- **Categories:** any proposal must be paired with retiring or reconfiguring the two New Arrivals plugins; otherwise it is overwritten.
- **Duplicates:** the keeper decision depends on where per-product SEO is stored (P5), so the recommendation stays provisional until the SEO plugin source is seen.
- **Migration:** adds Cloudflare, existing Stripe/PayPal/tax plugins, Klaviyo, Meta/Google feeds, Matomo, Mailgun, the blog, and the custom plugins.
- **Scope:** the storefront needs blog, policy, contact, FAQ, reviews, and promo/new-arrivals equivalents, or an explicit decision to drop each.
